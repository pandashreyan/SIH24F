# 🏛️ Nagrik Aur Samvidhan: The Digital Judicial Hub

**Empowering Citizens through AI-Powered Constitutional Literacy**

Nagrik Aur Samvidhan is a state-of-the-art mobile platform designed for the **Smart India Hackathon**. It bridges the gap between complex constitutional law and the common citizen using advanced AI, interactive storytelling, and multilingual accessibility.

---

## 🚀 Key Features

### 🧠 Samvidhan AI (Legal Intelligence)
*   **AI Verdict Predictor (PRO)**: Uses Llama 3 to analyze legal scenarios and predict outcome probabilities with judicial reasoning.
*   **AI Legal Assistant**: A multilingual chatbot (English/Hindi) that provides instant answers to constitutional queries.
*   **Legal Drafter (RTI Generator)**: Automatically generates professional legal templates and RTI drafts based on user scenarios.

### 🎭 Interactive Learning
*   **Fight For Your Rights**: An interactive storytelling module where users navigate daily-life legal scenarios to learn their fundamental rights.
*   **Constitutional Crossword**: Gamified learning to test and improve legal knowledge.

### 🌍 Inclusivity & Accessibility
*   **Multilingual Support**: Seamless toggle between **English** and **Hindi**.
*   **Voice Assistant (TTS)**: Fully integrated Text-to-Speech engine for voice-assisted legal learning.

## 🛠️ Technology Stack

| Layer | Technology |
| :--- | :--- |
| **Mobile App** | React Native (Expo/CLI), Linear Gradients, Glassmorphism UI |
| **Auth Backend** | Spring Boot, JPA, H2 (In-Memory Database for Demo) |
| **AI Backend** | Flask, Ollama, Llama 3 LLM |
| **Logic/Utils** | Axios, React-Native-TTS, Vector Icons |

## 📦 Installation & Setup

### 1. AI Server (Flask)
```bash
cd Backend/"OLLAMA AND FLASK"
python ai_server.py
```

### 2. Auth Server (Spring Boot)
```bash
cd Backend
./mvnw spring-boot:run
```

### 3. Mobile App
```bash
npm install
npx react-native run-android
```
